01 · El desafío operativo

¿Cómo evitar que un pallet
se pierda en el proceso?

Cuando las áreas registran en archivos distintos, una diferencia puede descubrirse recién al cargar o cerrar el embarque.

↔

Datos duplicados

TALLY, registros de PT y Calidad pueden quedar separados o desactualizados.

⌛

Esperas

La inspección secuencial retrasa el avance de la carga.

?

Responsabilidad difusa

Cuesta identificar quién preparó o revisó cada unidad física.

▤

Documentos dispersos

Fotos, aprobaciones y actas pueden terminar en carpetas diferentes.

02 · La solución

Una sola orden.
Una historia completa.

BALSASUD conecta la documentación autorizada con los registros físicos de PT, Calidad y Embarque.

  • ✓Información por orden, ITEM ID, espesor y pallet/caja.
  • ✓Calidad puede inspeccionar desde que PT registra el primer pallet.
  • ✓La liberación depende de una conciliación completa y aprobada.
  • ✓Actas, firmas, QR y auditoría quedan vinculados al embarque.

Una plataforma · cuatro áreas

La operación comparte el mismo estado.

El equipo puede seguir qué se autorizó, qué se registró, qué se inspeccionó y qué está listo para el siguiente paso.

05 · Lectura de fuentes

De PDFs a datos
listos para revisar.

La orden puede iniciar desde los documentos operativos, reduciendo la reescritura manual de cantidades y productos.

  • ✓Lectura del TALLY SHEET y del Detalle de embarque FOR-OP-31.
  • ✓Previsualización y revisión antes de publicar.
  • ✓El Detalle no incluye ITEM ID: el sistema propone uno según espesor y requiere confirmación.
  • ✓Las diferencias o datos no reconocidos deben revisarse, no se silencian.

Revisión previa

Documento → productos → autorización

La fuente oficial permanece asociada a la orden y sirve como referencia durante la conciliación.

08 · Retorno de pallet corregido

Se corrige en PT.
Calidad reinspecciona.

El mismo pallet conserva su trazabilidad. Después de una corrección, no se considera aprobado hasta que Calidad lo revise de nuevo.

1

Calidad devuelve

Rechaza o solicita corrección y registra el motivo.

2

PT corrige

Edita el mismo pallet. Su estado cambia a “Corregido · pendiente de reinspección”.

3

Calidad reinspecciona

Abre el pallet y lo aprueba explícitamente para continuar.

El estado corregido se muestra en ámbar y mantiene bloqueada la liberación hasta la aprobación de Calidad.
▤

Tablas de pallets

Visible para Producto Terminado y Calidad, con acción de reinspección.

⌕

Filtro de Calidad

Filtro “Corregidos” para encontrar rápidamente los pallets pendientes.

▣

Resumen y documentos

Se refleja en el resumen de inspección, el acta y las exportaciones CSV.

▦

Control global

El control individual de pallets permite identificar este estado.

⚠

Conciliación

Aparece como hallazgo ámbar y bloquea la liberación mientras falte reinspección.

↺

Estado del despacho

La orden muestra “Corregido · pendiente de reinspección” mientras haya pallets en retorno.

13 · Plataforma y datos

Una plataforma web.
Datos conectados al proceso.

El sistema se compone de una interfaz operativa, servicios backend, hojas de control y archivos de respaldo/evidencia.

  • ✓Interfaz web adaptable a computadora, tablet y celular.
  • ✓Google Apps Script como capa de servicios de la operación.
  • ✓Google Sheets para los registros estructurados del sistema.
  • ✓Google Drive para documentos y carpetas por año, mes y embarque.
🖥
Aplicación BALSASUD

Vistas de trabajo diferenciadas por rol.

⚙
Apps Script API

Servicios para registrar, validar y auditar operaciones.

▦
Sheets + Drive

Datos estructurados, documentos y evidencias del embarque.

El funcionamiento conectado en producción depende de la configuración vigente del endpoint y permisos de Google.

14 · Disponibilidad multi-dispositivo

Mismo sistema.
Desde cualquier pantalla.

BALSASUD es una aplicación web. No importa si el usuario entra desde una computadora de oficina, una tablet en planta o un celular en el patio de carga: ve el mismo estado de la orden.

🌐

Web responsive

La interfaz se adapta a computadora, tablet y celular.

🔐

Acceso por usuario

☁

Datos centralizados
